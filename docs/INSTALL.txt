MenuCraft 0.5.1 / build 12
系统要求：macOS 13 或更高；支持 Apple Silicon 与 Intel。

安装
下载 MenuCraft-universal.dmg，一个安装包适用于 Apple Silicon 与 Intel Mac。
1. 将 MenuCraft.app 拖到 Applications（应用程序）。
2. 从应用程序打开 MenuCraft，点击“启用右键扩展”。
3. 在系统的 Finder 扩展设置中勾选“MenuCraft”。
4. 打开文稿、下载、桌面或设置中添加的目录，右键查看“MenuCraft”。

本包使用本地临时签名，尚未经过 Apple 开发者签名与公证。
如果 macOS 阻止打开，可在“系统设置 > 隐私与安全性”中使用“仍要打开”。
不要关闭系统安全检查；只对来源明确的 MenuCraft 进行允许。

权限
创建和移动文件：macOS 按需询问目录访问。
进入终端：首次使用时允许控制您选择的终端。
显示/取消显示隐藏文件：需要允许MenuCraft使用辅助功能，用于发送 Finder 自带快捷键；无需重启 Finder。
滚动控制：允许 MenuCraft 使用辅助功能，并按系统提示重新打开应用。当前四开关版本只处理滚轮事件，不需要输入监控。
升级后若辅助功能显示允许但应用检测未通过，请移除旧 MenuCraft 条目再添加 /Applications/MenuCraft.app。其他文件操作不需要辅助功能。

操作规则
文件创建、移动和复制不会静默覆盖同名文件。
剪切先记录待移动项目，目标目录右键“粘贴到这里”才执行移动。
解除文件夹只展开一层，含隐藏项；全部成功且原目录为空后才移入废纸篓。
批量重命名与桌面替身默认关闭，可以在菜单设置中开启。
多选后新建文件夹使用 Finder 自带入口。

关闭最后一个设置／操作窗口后界面进程退出以释放内存，核心留在菜单栏，滚动与后台文件任务继续。重新打开时恢复窗口和设置。退出MenuCraft会清空尚未粘贴的剪切记录。
设置与操作记录保存在 ~/Library/Application Support/MenuCraft。

卸载：退出MenuCraft，在系统设置停用其 Finder 扩展，将 MenuCraft.app 移入废纸篓。
如需清除配置，可手动删除上述 MenuCraft 设置目录。

新增能力
滚动页面只有鼠标、触控板、纵向、横向四个开关；选中的设备在选中的方向上反转，关闭设备开关保留系统方向。滚动速度使用系统默认；菜单栏可暂停/恢复。
普通鼠标滚轮与 Mac 触控板分别控制；Magic Mouse 和软件平滑的鼠标滚动属于连续事件，当前跟随触控板选项。
右键“压缩为”选择 ZIP、7Z 或“更多格式”的九种格式后立即执行，保存到原文件所在目录。右键解压也直接执行；默认解压到同名文件夹，可在设置页改成当前目录。成功后没有完成弹窗。
压缩级别、分卷和加密使用设置页的默认值。加密时只询问本次密码；遇到错误会显示原因。设置页的手动文件选择功能保留高级操作窗口。
ZIP 加密密码限 1–99 个英文字符、数字、符号，中文密码请选择 7Z。
GZ/BZ2/XZ 单流格式仅支持一个文件，多项请选择 TAR 组合格式。
RAR/RAR5 仅解压；分卷从首卷开始；链接归档暂不解压。
MenuCraft 菜单项与子菜单连续排列，没有组间空行；Finder 外层菜单由系统管理。
许可证与压缩引擎对应源码在应用包 Contents/Resources/ThirdParty 中提供。

界面更新
侧栏保留顶部 MenuCraft 图标和工具名，移除底部版本号；版本见权限与设置页及“关于 MenuCraft”。
设置选择器采用短弹出按钮，开关右侧对齐。默认浅深色与强调色跟随系统。默认窗口外框 1000 × 700 pt，最小 860 × 620 pt；升级后重置旧版过大尺寸一次，之后记忆大小、位置和最近页面。
新建文件使用 380 pt 宽的紧凑输入表单，默认只选中文件名主体。
