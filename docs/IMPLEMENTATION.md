# MenuCraft 原生实现 0.5.1

日期：2026-10-01。对应 v0.4 设计；旧版说明见 IMPLEMENTATION-0.3.md 与 IMPLEMENTATION-0.1.md。

## 已接入

- 一个 MenuCraft.app，包含 AppKit 常驻核心、按需启动的 Contents/Helpers/MenuCraft.app、Finder Sync 扩展、滚动引擎和独立 7-Zip 引擎。设置进程的 bundle ID 为 local.menucraft.app.settings，主程序与扩展 ID 保持不变。
- 常驻核心负责配置持久化、权限、剪切记录、后台文件任务与滚动；设置进程只呈现界面并发送请求。两者通过同用户校验、0600 权限的本地 Unix socket 传递长度限定的 JSON 消息，密码只在本次请求内传输。配置修改带递增版本号，避免较早状态覆盖尚未确认的编辑。
- 关闭最后一个设置／操作窗口时设置进程退出，后台任务不终止。重新打开按需加载操作结果和重命名恢复记录。窗口位置、尺寸、最近页面与侧栏偏好从旧主程序域迁移到设置域。常驻核心不链接 SwiftUI，两个应用均声明并包含原图标资源，通过硬链接共享同一份存储，避免 Dock 在启动时回退到占位图标。
- 状态更新按变化发布，卷列表由系统挂载／卸载通知更新，3 秒容忍延迟的检查保留权限恢复、旧滚动工具共存与 Finder 外部隐藏文件偏好检测。诊断仅在状态改变时写入；累计计数通过 menucraft://diagnostics 或内部诊断请求刷新。
- 六页 SwiftUI 设置窗口，英文产品名、蓝紫导航、浅深色外观、搜索；左侧栏可折叠为图标栏，折叠按钮始终在头部最右端。重命名为独立操作窗口。
- 现有模板、路径、应用、收藏、剪切粘贴、移动复制、解除、隐藏显示、可选重命名和替身功能保留。
- Finder 压缩子菜单提供 ZIP、7Z，“更多格式”再展开全部九种格式；文件夹／多选禁用单流格式。解压菜单提供默认、同名文件夹、当前目录及选择目录。仅对支持的归档显示解压入口。设置图标改用系统模板，保证深色可读。
- 主菜单及子菜单取消 MenuCraft 插入的所有 separator，动作连续显示，包含设置入口之前。Finder 外层菜单由系统与其他扩展管理。
- SettingsSection／SettingsRow 统一设置行：标签左侧，短弹出选择器与开关右侧；表单最大 720 pt。目录默认收起，常用偏好首屏可见。侧栏保留顶部 MenuCraft 图标和名称，移除底部版本区。
- 默认窗口外框 1000 × 700 pt，最小 860 × 620 pt。新 autosave 键迁移旧版大窗口一次，之后保存尺寸与位置；AppStorage 恢复最近页面，关键词搜索支持密码、格式、外观与设备。
- FileNamePanel 使用独立 NSPanel，内容 380 × 188 pt，包含系统标题栏的实测外框约 380 × 216 pt。小文件图标、短说明、截断路径与完整提示，默认只选中文件名主体。实时校验，Return 创建、Escape 或关闭取消；文件创建与重名规则保留。
- 手动归档窗口内容缩为 560 × 470 pt，确认操作的冲突选择器宽 180 pt。版本从应用元数据读取，在设置页与关于窗口显示。
- 默认外观为跟随系统，AppModel 使用 NSApp.appearance = nil。原生按钮、开关和选择器保留系统默认配色；导航读取 NSColor.controlAccentColor。0.4.1 移除根视图的动态 NSColor tint 覆盖，修复 0.4.0 活动窗口下开关与选择器变红的问题。窗口背景、分隔线、正文与说明使用系统动态颜色。

## 滚动

0.5.0 保留 build 6 的设备判定、事件修改和四开关配置；仅将 150 ms 运行循环轮询改为阻塞等待事件。停止时显式唤醒并停止运行循环，快速暂停／恢复与睡眠唤醒可重新连接。

Sources/Scroll/MCScrollEngine.m 改编自 Scroll Reverser 1.9 的 MouseTap.m（Apache 2.0），保留 LICENSE、NOTICE 与来源说明。

build 5 使用单一主动滚轮监听，回调只读取内存配置。普通非连续滚轮按鼠标选项处理，连续事件按触控板选项处理；不再用缺失的两指事件、333 ms 超时或上一次设备判断改变方向。每个事件独立判定，启动、手势阶段与惯性都保留同一规则。适用于普通鼠标滚轮和 Mac 触控板；Magic Mouse／软件平滑的滚轮同样产生连续事件，当前跟随触控板选项，不能承诺将它们区分成普通鼠标。

滚动页只有鼠标、触控板、纵向、横向四个开关；只有设备与轴同时选中才反转。保留系统速度，旧 enabled／step／raw 字段可读取，但不再影响四开关反向规则。菜单栏暂停仍保留，修改开关会恢复控制。原先触摸时间策略与 build 4 MayBegin 补丁的实机问题记在 NATIVE_QA-0.3.md。

HID 调整通过动态查找上游非公开符号提供增强；符号不存在时使用 Core Graphics 字段。横轴乘数已修正为自身方向。系统版本变化、Magic Mouse、第三方设备、远程桌面和应用特有手势仍需要兼容性实测。

真实状态检查辅助功能和滚轮监听创建结果。当前不创建被动手势监听，不需要输入监控。旧 Scroll Reverser 运行时，新引擎保持停止，避免重复反转。退出移除监听，唤醒重新连接。scroll-status.json 仅保存状态、设备分类和累计事件计数，不保存事件内容或键盘输入。

首次升级读取旧偏好并补齐上游默认值；本机最终设置为鼠标反转、触控板不反转、纵向反转、横向不反转、系统默认速度。scrollMigrated 标记防止后续覆盖新设置。

## 压缩与解压

应用资源内确定路径的官方 7zz 26.03 二进制，通过 Process 参数数组启动，无 Shell 拼接；按发布包架构裁剪。ZIP／7Z／TAR 直接创建；TAR.GZ／TAR.BZ2／TAR.XZ 分两阶段；GZ／BZ2／XZ 仅单文件。RAR／RAR5 只解压。

ZIP 和 7Z 支持 AES-256。ZIP 密码遵循引擎的 1–99 个可打印 ASCII 字符限制；7Z 可使用 Unicode 密码和文件名加密。密码只保留在任务内存中，通过标准输入管道传入，不存配置、不进参数或日志。

build 6 的右键动作进入 quickArchive：选定格式覆盖默认格式，保留级别／分卷等默认值，并关闭不适用的加密选项。结果直接保存到源目录，多包分别保存到各自目录；同名自动编号。prepareOperation 不展示设置窗口，成功时 finishOperation 不展示结果弹窗，Finder 用非激活方式传递请求。加密压缩只询问密码；解压遇到 passwordRequired 才询问并重试，错误单独报告。设置页手动选择文件仍进入 ArchiveEditor，保留高级操作窗口。

ArchiveConfiguration 增加 extractToSameNameFolder，旧配置缺少字段时默认为 true；原默认值不丢失。没有密码字段。右键更多格式与默认解压规则通过菜单和迁移测试验证。

输入复制到目标内 0700 临时目录，成功后发布结果。同名自动添加序号，原文件保留；分卷先检查首卷和连续卷；失败取消清理临时输出。运行取消先终止进程，超时再强制停止。发布失败或取消会尝试回滚已交付项目。

普通文件暂存使用 copyfile 的克隆优先及排他创建选项，保留数据与元信息；不支持克隆时正常复制。目录和链接继续使用 Foundation 原行为，避免递归克隆改变目录层级和冲突规则。解压技术清单按字节块解析，保留 32 MiB 清单限制，处理跨块 Unicode 行与重复路径；普通输出只保留最近 64 KiB。取消由一次回调终止进程，必要时 2 秒后强制终止，移除 100 ms 取消轮询。

解压先读取技术目录清单，拒绝绝对路径、上级路径、Windows 驱动器、重复或大小写冲突条目、不能解析的清单及链接。当前保守拒绝所有符号／硬链接，不承诺解开此类归档。BZ2／XZ 无名称数据流作为专门情形处理；TAR 组合校验内外两层。发布前再次检查链接与路径范围。同目录输出直接子项整体保留，嵌套文件夹不做合并覆盖。

压缩执行队列和滚动运行循环独立。进度使用引擎输出；准备复制阶段可能等待当前系统文件复制结束。

## 迁移与发布

配置版本迁移为 3，保留旧动作开关、排序、自定义模板内容和 ID、收藏、路径及应用。首次加入压缩与解压默认动作，旧可选停用项保持停用。bundle ID、menucraft scheme 和 Application Support/MenuCraft 路径不变。

分别提供 arm64、x86_64 和双架构主程序／界面／扩展／7zz，ad-hoc 签名严格校验。构建采用全模块优化并移除调试和局部符号。7-Zip LICENSE、完整对应源码以及 Scroll Reverser LICENSE／NOTICE 随应用提供，图标内容保留。原生应用不是网页原型。

Finder 菜单上下文按菜单保存一份文件列表，动作保存轻量 ID；上下文限时 5 分钟、总路径数据上限 16 MiB。不同菜单上下文互不覆盖，重建菜单项使用 tag 回查同一引用；点击才生成原 ActionRequest。扩展仍不执行文件操作。菜单图标按样式缓存，观察目录未改变时不重复设置。

重命名恢复的目录指纹逐项编码为原有 JSON 数组字节并流式更新 SHA-256，与旧格式兼容。已持久化的大结果／恢复数组在界面关闭后释放，重新打开按需读取；恢复记录写入失败时仍保留本次会话中的记录。

本机没有 Developer ID 和公证身份。升级后的辅助功能旧条目可能显示开启但实际失效，需要通过系统设置重新添加当前应用；不写入 TCC 数据库，不重置其他应用权限。DMG 打包可用 SKIP_BUILD=1 包装已验证且已安装的同一个构建。

检查结果与剩余硬件、系统限制见 NATIVE_QA-0.5.md；旧界面验证见 NATIVE_QA.md。
