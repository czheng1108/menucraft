MenuCraft 的首个公开版本，提供 macOS Finder 右键文件操作、文件模板、压缩解压与滚动控制。

下载 MenuCraft-universal.dmg：一个安装包，同时支持 Apple Silicon（M 系列）和 Intel Mac。

系统要求：macOS 13 或更新。

当前安装包使用本地 ad-hoc 签名，尚未经过 Developer ID 签名和 Apple 公证。首次打开可能需要在系统设置中手动允许。请参阅安装说明；Finder 扩展和辅助功能权限按需开启。

设置界面按需启动，关闭最后一个窗口后退出；后台文件任务与滚动控制继续运行。保留菜单排序、设置、窗口位置与已有文件操作功能。修复 Dock 中的空白图标与 MenuCraftSettings 名称。

包含 SHA256SUMS、安装说明和许可证文件。Intel 构建不等同于完成 Intel 硬件上的全部交互验证；Finder 扩展、滚动与系统权限仍需各环境实机验证。
